# SWYNEX-Machine-Learning-Model

## Task 2 – Machine Learning Model

This project was completed as part of the SWYNEX Technologies Machine Learning Internship – Task 2.

### Objective
To train and evaluate machine learning classification models using the Titanic dataset and compare their performance.

### Dataset
Titanic Dataset

### Models Used
- Logistic Regression
- Random Forest Classifier

### Data Preprocessing
- Removed unnecessary columns
- Handled missing numerical values using median imputation
- Handled missing categorical values using most-frequent imputation
- Applied One-Hot Encoding to categorical features
- Split the dataset into training and testing sets

### Evaluation Metrics
The models were evaluated using:
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- ROC-AUC

### Conclusion
The performance of Logistic Regression and Random Forest was compared using the evaluation metrics. The model performance differed across the metrics, demonstrating how different machine learning algorithms can produce different results on the same dataset.
